# Kauzz Palette Tool

Ferramenta estática para:

- importar uma imagem;
- extrair a paleta predominante;
- agrupar cores por hues próximos;
- ordenar cada grupo do mais escuro para o mais claro;
- importar paletas em JSON;
- substituir as cores da imagem com base na paleta importada.

## Formato da paleta importada

Você pode importar:

```json
["#1E1E1E", "#F4D35E", "#6A4C93"]
```

ou:

```json
{
  "colors": ["#1E1E1E", "#F4D35E", "#6A4C93"]
}
```

## Como abrir

Abra o arquivo `index.html` no navegador.
